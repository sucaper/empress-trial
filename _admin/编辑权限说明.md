# 网站编辑与管理员权限说明

## 权限模型（静态站点）

本站为 **Quarto 静态网站 + Git 版本管理**，无独立后台登录。编辑权限即**仓库读写权限**：

| 角色 | 权限 | 说明 |
|:---|:---|:---|
| 管理员（仓库 Owner） | 全部权限 | GitHub 仓库 owner；Cloudflare Pages 控制台管理 |
| 编辑（含 AI 助手） | 内容编辑与提交 | 修改 `*.qmd` / `data/*.json`，本地 `quarto render` 验证后 `git commit` 推送 |
| 访客 | 只读 | 访问 `*.pages.dev`（或自定义域名） |

管理员（网站负责人）可随时在 GitHub → Settings → Collaborators 中增删编辑者。

## 编辑工作流

1. 编辑内容：
   - 普通页面 → 改对应 `*.qmd`（如首页 `index.qmd`、治理 `governance.qmd`）
   - 成员 → 改 `data/members.json`，运行 `python scripts/build_members.py`
   - 发布文件 → 文件放入 `files/` 对应子目录，并在 `documents.qmd` 登记
2. 验证：`quarto render`（本地输出 `_site/`）
3. 发布：`git add -A && git commit -m "说明" && git push`
4. Cloudflare Pages 检测到推送后自动构建部署（构建命令见 README）

## 敏感信息红线

- 未公开的研究结果数据（入组数、疗效数据等）**不**上网站
- 委员会名单、中期报告等发布前需经指导委员会审核
- 内部进展只在「最新动态」以公开口径更新
